# 서울 전월세 2026

서울 자치구와 동을 선택하면 해당 동의 2026년 전월세 실거래 신고 데이터를 모두 조회하는 Cloudflare 기반 웹 애플리케이션입니다.

## 주요 기능

- 서울 25개 자치구 선택
- 선택 자치구의 2026년 법정동 목록을 실제 신고 데이터에서 생성
- 선택 동의 모든 2026년 전월세 신고 건을 자동 페이지네이션으로 조회
- 보증금·월세 평균과 계약별 상세 표 제공
- 서울시 API 키는 브라우저 및 저장소에 노출하지 않고 서버 비밀값으로만 사용

## 환경 변수

로컬 실행용으로 `.env.example`을 `.env`로 복사한 뒤 다음 값을 설정합니다.

```env
SEOUL_API_KEY=발급받은_서울시_OpenAPI_키
```

`.env`는 Git에서 제외됩니다. Cloudflare 배포 환경에서는 `SEOUL_API_KEY`를 비밀 환경 변수로 등록해야 합니다.

## 실행

```bash
npm ci
npm run dev
```

## 데이터 출처

서울 열린데이터광장 `tbLnOpendataRentV` (서울시 부동산 전월세가 정보)
